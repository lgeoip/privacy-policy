01

General provisions

This Privacy Policy (hereinafter referred to as the "Policy") describes the procedure for collecting, processing, storing and protecting information related to personal data when using the web service tutuurg.github.io/lgeoip (hereinafter referred to as the "Service").

The service is designed to provide information about geolocation, network parameters, and the likelihood of anonymization of IP addresses.

By using the Service, you agree to the terms of this Policy.
02

What data is being processed

2.1. Automatically collected data

When accessing the Service, the following data may be processed:

  • IP address (including IPv4 and IPv6) is personal data in accordance with the legislation of the Republic of Belarus;
  • Browser time zone (if provided by the user via the tz parameter);
  • HTTP request headers (User-Agent, Referer, and other technical metadata).
03

Purposes of data processing

The processing of the IP address is carried out exclusively for the following purposes:

  • Determining the approximate geographical location (country, city, region);
  • Definition of Internet Service Provider (ISP), Autonomous System (ASN) and Network;
  • Checking for the use of anonymizing technologies (proxy, VPN, Tor);
  • Generating Service usage statistics (without user identification);
  • Ensuring the operability and security of the Service.
04

Legal grounds for processing

Personal data is processed based on the user's explicit consent, which is requested upon the first visit to the Service's web page.

Consent can be revoked at any time via the web page interface ("Revoke Consent").
05

Data storage and protection

  • IP addresses are not stored in permanent logs or databases of the Service.
  • Technical logs (request time, request type) can be stored temporarily in the server's RAM and automatically deleted upon restart.
  • Usage statistics (number of requests, unique IP addresses) are aggregated, without reference to specific IP addresses.
  • Data is transmitted between the browser and the server using the secure HTTPS protocol.
  • The service does not use cookies or sessionStorage to track users.
06

Transfer of data to third parties

The Service does not transfer IP addresses or other personal information to third parties. All database queries (MaxMind, IP2Proxy) and analysis logic are performed locally on the project server. Your IP address is not transmitted to an external API for analysis.

07

Your rights

In accordance with the GDPR and other applicable regulations, you have the right to:

  • Consent to data processing;
  • Revoke consent at any time;
  • Request clarification, blocking or deletion of your personal data if they are processed in violation of the law;
  • To receive information about the processing of your personal data.

To exercise these rights, you can contact us using the contact information provided in section 9.

08

Automatic system learning

The service includes an auto-learning function to determine ASNs associated with hosting providers and VPNs. This happens automatically when an IP is detected with a high probability of anonymization. This information is stored in the local known_asns.json file in an impersonal form (only the ASN number and label).
